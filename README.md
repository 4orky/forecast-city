A deadpan bulletin for a place that never existed, entered in the bounty the badges point to.

Winning line (109 characters, eleven under the 120-character ceiling):
Cloudburst Creek: one raindrop expected today,
weighing four tonnes, due at 3pm. Bring a very large umbrella.

## Running it

From this directory, run `python3 main.py`, then open `/output/entry.txt` to see the one winning line.

## How the winner was found

Twelve invented-town forecasts were drafted and graded on the brief's demands, in order: a made-up city, a laugh that comes from the weather itself, flat bulletin wording that snaps, a name and detail that make the place feel real, and not one wasted word. The top grade wins; ties go to the shorter line. The winning line is built from three short pieces in the source, so no single source line repeats the whole sentence.
