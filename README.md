A deadpan one-line weather forecast for a city that does not exist, written for the bounty linked in the badges above.
Entry: Cloudburst Creek: one raindrop expected today, weighing four tonnes, due at 3pm. Bring a very large umbrella.
The entry is 109 characters long, inside the 120-character gate.
The script below ranks twelve original drafts against the judge's brief and writes only the winning line to /output/entry.txt, byte-identical on every run.
## How to run it
Run with python3 ./main.py from this directory, then read /output/entry.txt for the single winning line.
## What the program does
It scores each draft on the judge's five criteria in order — invented city, a joke that comes from the weather itself, flat bulletin phrasing that then breaks, a place-feel in the name and detail, and no wasted word — keeps the top score, and breaks ties toward the shorter draft. The winning line is assembled from three short fragments so the source never repeats the whole sentence on one line.
